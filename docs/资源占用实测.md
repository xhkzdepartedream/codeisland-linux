# 资源占用实测

本文件只放**实测数字**，每条都带口径。估计值单独标注，不与实测混排。

采样日期：2026-10-13。机器：CachyOS，内核 7.2.9，kwin 6.7.5，Wayland。

## 构件体积

| 构件 | 体积 | 口径 |
|---|---|---|
| `codeisland-bridge` | 342.2 KB | 实际字节数 ÷ 1024 |
| `codeisland-daemon` | 387.1 KB | 同上 |

`[profile.release]` 用 `opt-level = "z"` + `lto = true` + `codegen-units = 1` + `strip = true`。

## 常驻程序（`codeisland-daemon`）

| 指标 | 实测 | 口径 |
|---|---|---|
| RSS | **2.5 MB** | `ps -o rss`，启动后 3 秒采样；1000 个事件处理完之后仍是 2.5 MB |
| VSZ | 3840 KB | 同一个采样点 |
| 线程数 | **1** | `ps -o nlwp`，空载。每来一个连接才临时起一个线程，处理完就退 |
| 空载 CPU | **10 秒内 0.000 秒** | 读 `/proc/<pid>/stat` 的 utime+stime，间隔 10 秒取差值，除以 `getconf CLK_TCK`。**0 表示它阻塞在 accept 上，没有轮询、没有定时器** |
| 事件吞吐 | **28266 事件/秒**，平均 0.04 ms/事件 | 单线程循环发 1000 个真实 socket 连接，每个连接发一个事件、等回复、关闭 |

## 短命程序（`codeisland-bridge`，每次工具调用启动一次）

| 指标 | 实测 | 口径 |
|---|---|---|
| 启动到退出 | **中位 0.29 ms，最小 0.27 ms** | 60 次 `subprocess.run`，墙钟时间，取中位数。走的是「socket 不存在」这条最常见的路径 |
| 对照：空 Rust 二进制 | 中位 0.26 ms | 编译一个空的 `fn main(){}`，同样 40 次采样 |
| 对照：`python3 -c pass` | 中位 7.14 ms | 40 次 |
| 对照：`node -e 0` | 中位 17.81 ms | 40 次 |

**这组数字的边界**：只测了启动和退出，没有测真实 hook 载荷下（要 JSON 解析、要算 summary）的耗时，也没有测常驻程序正忙时连接被排队的延迟。桥接程序在「有 daemon」路径上还要多一次 socket 往返，那部分延迟没单独测。

**这组数字的实际意义有限**，说清楚：假设一小时 200 次工具调用，用 Rust 而非 Python 写桥接程序，一小时省约 1.4 秒。绝对量上不重要。选 Rust 真正的价值在常驻程序那一行——它把一整类运行时内存开销（Python 解释器、Node 堆）从常驻进程里删掉了，换来 2.5 MB 和 0 空载 CPU。

## 尚未实测的部分

**界面（阶段 1）的内存与 CPU 完全没有测。** 现在的估计：Qt6 + QML 运行时约 60–90 MB RSS。**这是估计，不是实测，不要当成结论。** 阶段 1 做完会在这里补上真实采样。

## 技术栈选型的依据（排除法）

| 方案 | 处置 | 原因 |
|---|---|---|
| Rust | **采用** | 上表的 2.5 MB / 0 空载 CPU / 342 KB 二进制 |
| Python | 排除常驻程序 | 内存基线 15–25 MB、启动 7.14 ms（实测）。它唯一的优势是能直接抄上游那份 609 行的 Python 远程 hook，但重写成本很低，不值得为它换掉常驻程序的语言 |
| Node | 排除 | `node -e 0` 启动 17.81 ms（实测），内存基线更高 |
| Swift | 排除 | 本机没装工具链（`swift`、`swiftc` 均不存在，已确认） |
| Electron | 排除界面 | 内存 150–250 MB 起，和目标直接冲突 |
| Tauri | 排除界面 | 底层是系统 WebKitGTK，在 KDE 上引入整条 GTK 依赖链，且毛玻璃和形变效果受限 |
| Qt6 + QML | **采用界面** | 毛玻璃、形变、动画都要靠它；本机 `layer-shell-qt`、`qt6-declarative`、`kdeclarative`、`plasma-integration` 均已安装 |
