## 一、动手前先做（环境自检，2 分钟）

```bash
cd ~/apps/codeisland-linux
export PATH=$HOME/.cargo/bin:$PATH

# 1) 是不是有多个 daemon 抢同一个 socket？（本会话就栽在这里）
for pid in $(ls /proc | grep -E '^[0-9]+$'); do
  exe=$(readlink /proc/$pid/exe 2>/dev/null) || continue
  case "$exe" in */codeisland-*) echo "$pid $(basename $exe) ${exe#*codeisland-linux/}";; esac
done
# 期望：最多各一个 codeisland-daemon / codeisland-shell。
# 看到 "(deleted)" 的残留——它在占 socket，你的 state 和截图都会是旧的，先 kill -9。

# 2) 跑一次全量，确认基线
cargo test --release --workspace 2>&1 | grep "test result"
# 期望：4 / 87 / 54 passed，0 failed。

# 3) 栈死了就起（重启后不会自启，systemd 服务没装）
nohup target/release/codeisland-daemon > /tmp/ci-daemon.log 2>&1 &
CODEISLAND_QML_DIR=$PWD/shell/qml nohup shell/build/codeisland-shell > /tmp/ci-shell.log 2>&1 &
```

**杀进程纪律（本会话又差点自伤一次）**：只用 `readlink /proc/$pid/exe` 取可执行文件路径判断，**绝不用 `pkill -f`**；按 cmdline 匹配时必须**从头锚定**（`case "$cmd" in "python3 -u scripts/hold-card.py"*)`），因为你自己那条 `bash -c '...'` 的 cmdline 里也含有同样的字符串。

## 三、本机必撞的坑（速查，只列下一个 agent 一定会遇到的）

- **GitHub 直连不通**（`raw.githubusercontent.com` → DNS 0.0.0.0；`github.com` TCP 超时）。用**已登录的 `gh api`** 取仓库内容：`gh api repos/<owner>/<repo>/contents/<path> --jq .content | base64 -d`。截图同理。vault 有笔记：`facts/工具/GitHub 直连不通时用已登录的 gh CLI…`。
- **`/tmp/cu/` 里 kcu 的截图会被清理**：`capture_*` 返回后**立刻 `cp` 出来**再用。且**别只看文件名就当真图**——本会话出现过两张"不同源"的裁剪**逐字节相同**（都是 112925 字节），那是过期文件。
- **截图回传**：> 约 12MB 的 PNG、> 约 200KB 的 JPEG 都传不回上下文。裁一小块、压到 **< 100KB**（JPEG quality ~80）再 `read`。
- **`kcu_click` 标称"逻辑坐标"但对 layer-shell 药丸（`x=894,y=6,260×34`）点了没反应**——别在这上面耗。**要展开面板就挂真卡**（`needsAttention` 会让它自动展开），或临时把 `main.qml` 的 `property bool pinned: false` 改成 `true`（QML 从源码目录读，改完不用重编译；**改完记得改回**）。
- **QML role 名与 delegate 属性名必须逐字相同**：`sessions_model.cpp` 里 role 名写成 `status_stated`、delegate 写 `statusStated` → **delegate 静默实例化失败，整个会话列表消失，且不打印任何错误**。单元测试和 view socket 都看不见，只有截图能发现。
- **`pgrep -x` 有 15 字符上限**：`codeisland-daemon`（17 字符）永远匹配不到，改用 `/proc` 扫描。
- **面板高度有依赖链**：`expandedHeight ← expandedContent.implicitHeight`；`anchors.fill: parent` 若是空列会塌成 0。会话行**在 Repeater 之外**的 "+N 更多" 不受影响，容易被误读成布局 bug。
